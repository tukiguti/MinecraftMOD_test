# バージョンアップ記録（1.19.4 → 1.20.1）

実施日: 2026/03/01

## 1. 移行前後の環境

| 項目 | 移行前 | 移行後 |
|---|---|---|
| Minecraft | 1.19.4 | 1.20.1 |
| Forge | 45.3.0 | 47.3.0 |
| Java | 17 | 17（変更なし） |
| ForgeGradle | 6.0〜6.2 | 6.0〜6.2（変更なし） |
| assetIndex | 3 | 5 |
| mcpVersion | 20230314.122934 | 20230612.114412 |

## 2. 移行の判断理由

- レベル・マナ・ステータスの基本実装が完了した段階で、チャンピオンスキル等の本実装前の今がバージョンアップのコストが最小
- 1.20.1は Forge が引き続きサポートされており、コミュニティリソースが豊富
- 1.21以降（NeoForge）への移行は設計が固まってから再検討

## 3. 変更ファイルと内容

### gradle.properties
```
minecraft_version: 1.19.4 → 1.20.1
minecraft_version_range: [1.19.4,1.20) → [1.20.1,1.21)
forge_version: 45.3.0 → 47.3.0
forge_version_range: [45,) → [47,)
loader_version_range: [45,) → [47,)
mapping_version: 1.19.4 → 1.20.1
```

### level/Hud.java
- `GuiComponent` クラスが廃止 → `extends GuiComponent` を削除
- `PoseStack poseStack = event.getPoseStack()` → `GuiGraphics guiGraphics = event.getGuiGraphics()`
- `RenderSystem.setShaderTexture(0, texture)` + `blit(poseStack, ...)` → `guiGraphics.blit(texture, ...)`（テクスチャ指定を blit 内に統合）
- `font.draw(poseStack, text, x, y, color)` → `guiGraphics.drawString(font, text, (int)x, (int)y, color)`
- スケーリングは `guiGraphics.pose().pushPose()` / `scale()` / `popPose()` で実施

### status/StatusHud.java
- `Hud.java` と同様の変更（GuiComponent廃止、GuiGraphics移行）
- `drawString(poseStack, font, text, x, y, color)` → `guiGraphics.drawString(font, text, x, y, color)`

### level/PlayerDataManager.java
- `player.getLevel()` → `player.level()`（1.20.1でメソッドがフィールドアクセス形式に変更）

### .vscode/launch.json
- `gradlew genVSCodeRuns` で再生成（手動編集不要）
- 主な変更: forgeVersion / mcVersion / mcpVersion / assetIndex / securejarhandler バージョン（2.1.6 → 2.1.10）

### .vscode/tasks.json
- `genVSCodeRuns` 再生成後に `./gradlew` → `gradlew.bat` に手動修正（Windows cmd.exe 対応）

### .gitignore
- `run-data` を追加（datagen実行時の生成ファイルを除外）
- `.vscode/launch.json` を追加（絶対パスがハードコードされるため、各自 `genVSCodeRuns` で生成する運用に）

## 4. 移行手順（再現手順）

```
# 1. gradle.properties を更新（上記の値に変更）

# 2. コンパイル確認
cd lolmod
gradlew.bat compileJava

# 3. Eclipse プロジェクトファイルを再生成（VS Code の Java 拡張機能用クラスパス更新）
gradlew.bat eclipse

# 4. VS Code 起動設定を再生成
gradlew.bat genVSCodeRuns

# 5. tasks.json の ./gradlew を gradlew.bat に修正（Windows用）

# 6. VS Code で Java: Clean Java Language Server Workspace を実行して再起動
```

## 5. 移行時に発生したエラーと対処

| エラー | 原因 | 対処 |
|---|---|---|
| `GuiComponent cannot be resolved` | 1.20.1で廃止 | クラス継承を削除し GuiGraphics に移行 |
| `getPoseStack() is undefined` | RenderGuiEvent の API 変更 | `getGuiGraphics()` に変更 |
| `getLevel() undefined for Player` | メソッド名変更 | `player.level()` に変更 |
| `drawString(Font,String,float,float,int) undefined` | float オーバーロードが存在しない | `(int)` キャストを追加 |
| `Module fmlloader reads another module named fmlloader` | launch.json が 1.19.4 のまま | `genVSCodeRuns` で再生成 |
| `./gradlew は認識されません` | cmd.exe で `./` が使えない | tasks.json を `gradlew.bat` に変更 |
